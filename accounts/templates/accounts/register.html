It: 1. Displays the UserRegistrationForm. 2. Collects username, first name, last name, email and passwords. 3. Sends the form to the Django backend using HTTP POST. 4. Displays validation errors returned by Django. 5. Provides a link back to the login page. It does NOT directly create users or save passwords. That work belongs to the Django view, form, authentication system, models and database. ============================================================ FRAMEWORK - DJANGO MVT ============================================================ Django uses an MVT-style architecture: MODEL ↓ accounts.User accounts.UserProfile ↓ Data stored in PostgreSQL VIEW ↓ accounts.views.register ↓ Receives the HTTP request Creates/processes UserRegistrationForm Checks whether submitted data is valid TEMPLATE ↓ accounts/templates/accounts/register.html ↓ Displays the form and validation feedback COMPLETE REGISTRATION FLOW: Browser / User ↓ Django URL ↓ accounts.views.register ↓ UserRegistrationForm ↓ register.html ↓ User enters registration information ↓
↓ HTTP POST request ↓ accounts.views.register ↓ UserRegistrationForm validation ↓ Valid? ├── NO │ ↓ │ Form + errors returned to register.html │ └── YES ↓ accounts.User ↓ UserProfile ↓ PostgreSQL ↓ Redirect to Login ============================================================ FRONT-END FRAMEWORK ============================================================ HTML: - Gives the page its structure. - Defines headings, paragraphs, forms, buttons and links. Bootstrap: - container - row / columns - cards - spacing - responsive breakpoints - buttons - alerts - typography utilities Font Awesome: - Supplies icons such as: chart-line user-plus shield-halved circle-exclamation static/css/styles.css: - MarketPulse dark theme - Shared colours - Card styling - Form styling - Button styling - Borders - Muted text ============================================================ LECTURE CONNECTION: PROGRAMMING LANGUAGE FEATURES / CONCEPTS ============================================================ These are the building blocks being demonstrated in this file. 1. URL ROUTING {% url 'accounts:login' %} Django generates the correct URL from its named route. 8. SECURITY {% csrf_token %} Adds Django's CSRF protection token to the POST form. 9. HTTP / CLIENT-SERVER COMMUNICATION The browser sends submitted registration data to the server. 10. VALIDATION form.username.errors form.email.errors form.password1.errors form.password2.errors Validation rules belong to the form/backend. This template displays the resulting messages. 11.
